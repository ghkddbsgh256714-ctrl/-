# 루틴한장 (Routine Hanjang)

> 회원과 코치를 위한 직관적이고 가벼운 모바일 퍼스널 트레이닝 웹앱

## 🌟 주요 기능
- **오늘의 트레이닝**: 웨이트 트레이닝, 유산소 운동, 스트레칭/회복 운동 기록
- **실시간 운동 타이머 & 세트 기록**: 추천값 자동 제안, 휴식 타이머, 세트별 무게/횟수 조절
- **유산소 챌린지**: 트레드밀, 마이마운틴, 천국의계단, 실내사이클 등 코스별 트래킹
- **식단 및 생활 습관 기록**: 수면, 수분, 식단 상태 간편 기록
- **캘린더 & 체중 변화 그래프**: 주간/월간 운동 기록 및 몸무게 트래킹

## 🚀 배포 및 실행
